# 局部几何微调（液化法）—— 不磨皮地改五官位置

> 适用场景：用户要求**只调整某一处五官的位置/高低**，同时**明确要求不要磨皮、不要瘦脸、保持皮肤质感**。
> 实战来源：一次一寸白底证件照「鼻子左右不对称」修正的完整复盘（含用户主观方向与实测相反的经历）。

## 一、先判通道：这个问题不要用生成式修图

| 需求特征 | 正确通道 |
|---|---|
| 换衣服、换发型、换背景、整体重制 | 生成式图生图通道（见 SKILL.md 阶段 2） |
| **只改某处几何位置，要求保纹理/不磨皮** | **本文的液化形变（cv2.remap）** |
| 去水印、去文字 | 图像擦除工具，或本地 inpaint 脚本 |

**血的教训**：生成式图生图类服务对任何"局部微调"都会**整脸重绘**——表现为磨皮、瘦脸、提亮肤色，而目标部位几乎不变。
实测：连续三次提交，prompt 里写明"禁止磨皮、禁止瘦脸、禁止改动其他部位"，模型依旧全脸重绘。**不要在生成式通道上反复试，直接换液化。**

## 二、三步闭环

### 1. 量（先量再修，不要凭感觉）

```bash
$PY scripts/nose_liquify.py --image 原图.jpg --measure
```

暗部像素检测两侧鼻孔底缘 / 鼻翼底缘的 y 坐标，输出 Δ = 左 − 右：
- Δ = 0 → 齐平
- Δ < 0 → 画面左侧偏高（y 更小 = 更靠上）
- Δ > 0 → 画面左侧偏低

**这一步同时是说服用户的唯一硬证据**：拿 Δ 数值表 + 带测量线的前后对比图交付。
用户说"你没改"时，数据比解释有用得多。

### 2. 试档（一次给足档位，不要逐档问）

```bash
$PY scripts/nose_liquify.py --image 原图.jpg --ladder 2,4,6,8 --strip 对比条.png
```

生成「原图 + 各档」的裁剪对比条（每格标注档位），让用户指一个数字。
一次只给一版会让用户来回 5 轮；一次给 4~5 档通常 1 轮定稿。

**步长纪律**：峰值位移不要超过实测 Δ 的 1.5 倍。真实不对称常常只有 4~6px，一步给 10px 必然过头。

### 3. 定稿

```bash
$PY scripts/nose_liquify.py --image 原图.jpg --auto --out 修正.png    # 自动搜索齐平档位
$PY scripts/nose_liquify.py --image 原图.jpg --left-px 7.5 --out 修正.png  # 手动指定
```

输出后**再跑一次 `--measure` 验证** Δ 是否收敛到 ±1px，把前后 Δ 对比表交给用户。

## 三、原理与参数

```python
gauss = exp(-((x-cx)²/2σx² + (y-cy)²/2σy²))   # 以目标部位为中心的高斯权重场
map_y = y - d * gauss                            # 正 d = 该区域整体下压 d 像素
out   = cv2.remap(img, map_x, map_y, cv2.INTER_CUBIC, borderMode=cv2.BORDER_REPLICATE)
```

- 局部像素**整体平移**，纹理随之平移 → 毛孔/痘印/法令纹 100% 保留（这是生成式做不到的）
- 高斯权重平滑衰减 → 无缝、无重影
- 两个场有重叠，压左边会带动右边 1~2px → 所以用**实测 Δ 迭代定档**，不要几何换算

参数表（1181×1653 证件照基准）：

| 参数 | 值 | 调整影响 |
|---|---|---|
| 鼻翼中心 | 自动检测（约 (567,772) / (639,775)） | 换图无需手改 |
| σ | (58, 40) | 变小=效果点状；变大=牵连脸颊 |
| 有效档位 | 4 ~ 12px | 超过 12px 形变痕迹明显 |

## 四、沟通约定（避免方向翻车）

- 一律用**画面坐标**（画面左侧 / 画面右侧）。用户说"我的左边"时等于画面左侧，但**用户可能说反**。
- 用户主观方向与实测 Δ 相反是常态（光影明暗会造成错觉）→ **先量，把 Δ 给用户看**，并请他箭头标注截图确认。
- 发生分歧时不要辩论，直接出「实测方向」与「用户方向」两个版本让他挑。

## 五、边界

- 液化只改位置，**改不了形状**。用户要"鼻翼变小/鼻头变挺"这类改形需求时，液化只能局部缩放（把 map_x 也做同款高斯缩放），效果有限，需提前说明。
- 涉及投影/轮廓光影的"看起来不对称"，纯几何修正可能仍不满意 → 可选补一步局部 dodge/burn 亮度均衡（两侧鼻翼亮度对齐），但要放在几何修正之后做。
