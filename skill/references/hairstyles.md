# 发型库与脸型适配

## 一、证件照发型红线（不合格会被退件）

| 红线 | 说明 |
|---|---|
| 不遮眉眼 | 眉毛、眼睛必须完整露出，刘海不能盖住眉峰 |
| 露出双耳 | 两侧头发不能遮耳（部分系统要求尤其严格） |
| 发色自然 | 黑、深棕可；挑染、彩染、奶奶灰不行 |
| 不过长 | 男士不披肩，女士长发需扎起或束于耳后 |
| 不夸张 | 爆炸头、脏辫、厚重卷发不行 |
| 头顶不过分高 | 飞机头、大背头要注意别把头顶撑得太高，会显得头部比例失调 |

## 二、脸型 → 发型适配

| 脸型 | 特征 | 发型策略 | 推荐款 |
|---|---|---|---|
| 圆脸 | 脸部宽度接近长度，下颌圆润 | **增加顶部高度**拉长视觉比例，两侧收紧；避免两侧蓬松 | 微分碎盖、美式前刺、飞机头 |
| 方脸 | 下颌角明显，额头方正 | 用柔和纹理弱化棱角，顶部做出弧度 | 韩式纹理烫、括号刘海、自然抓刺 |
| 长脸 | 脸长明显大于宽 | **压低顶部**、两侧略留量增加横向宽度；留点刘海缩短脸长 | 短碎发、自然抓刺、圆寸 |
| 鹅蛋脸 | 比例均衡 | 基本百搭，按气质选 | 全部可试 |
| 心形脸 | 额头宽、下巴尖 | 两侧适当蓬松平衡额头，避免顶部过高 | 中分纹理、自然抓刺 |
| 扁头/头顶塌 | 颅顶低、头发贴头皮 | **核心是蓬松**：顶部留 5–7cm 做纹理，两侧不要推太光（推光会显得顶更塌） | 微分碎盖、韩式纹理侧分、羊毛卷碎盖 |

> **关键洞察**：亚洲男性最常见的"发型扁塌不时尚"问题，根源往往不是脸型，而是**两侧推太光 + 顶部贴头皮**。推太光会形成强烈的明暗对比，反而把"头顶不够饱满"暴露得更明显。对策是两侧保留渐变（不要铲平）＋顶部制造蓬松纹理。

## 三、发型库

### 短发型（清爽，好打理）

**1. 微分碎盖**
- 特征：顶部 5–7cm，剪碎打薄有层次，刘海在额前自然微分，两侧短但有渐变不推光
- 适合：圆脸、扁头、鹅蛋脸
- 风格：自然清爽、减龄少年感
- 定位：近两年最主流的男士发型，解决扁塌最直接

**2. 美式前刺（纹理前刺）**
- 特征：两鬓修剪利落，顶部短且向上前方抓出纹理，发根立起
- 适合：圆脸、方脸、鹅蛋脸
- 风格：精神利落、干脆有力
- 注意：额头完全露出，适合眉形好看的人

**3. 渐层层次短发**
- 特征：两侧低渐变（从耳下开始），顶部 3–5cm 做自然碎层次，无需烫染
- 适合：几乎所有脸型，尤其职场通勤
- 风格：简约精神、低调精致
- 定位：2025 主流款，最"安全"的选择

**4. 圆寸 / 短碎发**
- 特征：整体极短，长度均匀
- 适合：长脸、头型规整者
- 风格：清爽硬朗
- 注意：圆脸、扁头慎选，会把脸的宽度和头顶塌陷同时暴露

**5. 飞机头 / 碎发飞机头**
- 特征：顶部向中间集中并向上隆起
- 适合：圆脸、方脸（能有效拉长脸型）
- 风格：个性、痞帅
- 注意：头顶高度容易过高，证件照里要控制隆起幅度

### 中长型（偏成熟）

**6. 韩式纹理侧分（三七分）**
- 特征：三七分，顶部蓬松有纹理并偏向一侧，露出部分额头，两侧整齐收短
- 适合：圆脸、方脸、鹅蛋脸
- 风格：沉稳商务、成熟体面
- 定位：证件照最保险的"显气质"选择，拉长脸型效果好

**7. 括号刘海**
- 特征：刘海中分或六四分，两侧向内扣形成括号形状，头顶烫蓬松
- 适合：方脸、鹅蛋脸
- 风格：温柔、有型
- 注意：内扣刘海容易压住眉毛，要控制长度

**8. 轻熟侧背（侧分背头）**
- 特征：头发整体向后或向一侧梳理定型，顶部有支撑
- 适合：方脸、鹅蛋脸、五官立体者
- 风格：庄重正式、成熟稳重
- 注意：需要发量和发际线支持；发际线偏高的做起来容易显老

**9. 自然抓刺**
- 特征：比前刺长，鬓角留 5–8cm，整体柔和
- 适合：长脸、心形脸
- 风格：柔和稳重、温和有温度

**10. 羊毛卷碎盖**
- 特征：顶部烫出柔和的 S 型弧度，蓬松有空气感
- 适合：扁头、发量偏少者（显发量）
- 风格：随性、有质感
- 注意：卷度要控制，过卷会变"泡面头"；证件照里建议轻度卷

### 女士发型

> 女士证件照的发型红线比男士更严：**长发必须扎起或束于耳后**，两侧不得遮耳。

**11. 披肩直发**
- 特征：自然披肩，中分或偏分，发丝顺直不厚重
- 适合：鹅蛋脸、方脸
- 风格：温柔知性
- 注意：需完整露出双耳；严格规格要求扎起时，改用盘发

**12. 齐肩短发（自然 / 微内扣）**
- 特征：长度及肩，发尾自然或轻微内扣，两侧收于耳后
- 适合：圆脸、方脸、鹅蛋脸
- 风格：职场干练
- 定位：女士最"好打理又合规"的保险选择

**13. 马尾 / 盘发**
- 特征：头发全部向后扎起或盘起，面部与颈部线条完整露出
- 适合：所有脸型
- 风格：标准证件照、庄重
- 定位：**合规性最高的款式**，严格规格与政务场景首选

**14. 微卷长发**
- 特征：自然大波浪，卷度放松不夸张，整体向后或分于两侧
- 适合：长脸、鹅蛋脸
- 风格：时尚温柔
- 注意：卷度过大或蓬松过度会被判"不自然"，证件照建议轻度

**女士脸型适配补充**

| 脸型 | 发型策略 | 推荐款 |
|---|---|---|
| 圆脸 | 增加顶部高度，两侧收窄贴耳 | 高盘发、齐肩内扣、偏分直发 |
| 方脸 | 用弧度与层次柔化下颌角 | 微卷长发、侧分披肩发 |
| 长脸 | 增加两侧横向宽度，避免头顶过高 | 披肩直发、齐肩短发 |
| 鹅蛋脸 | 百搭 | 全部可试 |
| 心形脸 | 两侧适当蓬松平衡额头，避免顶部过高 | 齐肩短发、侧分披肩发 |

## 四、风格词对照（用于文件命名）

| 风格词 | 适用场景 | 常见搭配 |
|---|---|---|
| 经典正式 | 通用、最正式 | 黑色衬衫/西装 |
| 沉稳商务 | 简历、职场、商务往来 | 深蓝、深灰 |
| 低调干练 | 日常职场、内部证件 | 深灰、深蓝 |
| 简约精神 | 考试报名、学生证 | 墨绿、深灰 |
| 庄重正式 | 政务、法律、签证 | 酒红、深棕、西装 |
| 柔和稳重 | 通用、亲和力强 | 深棕、藏青 |
| 自然清爽 | 年轻化场景、社交 | 微分碎盖等年轻发型 |
