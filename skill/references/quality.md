# 画质与验收

## 一、第一条原则：文件体积 ≠ 清晰度

实测过的反例：369 KB 的成片比 411 KB 的更锐（Laplacian 方差 100 vs 148）。

**永远不要用"文件多少 K/MB"判断清晰度**，也不要为了让文件变大而提高 JPEG 质量 —— 那只会增大体积，不增加细节。

## 二、画质问题排查顺序（用户说"不清晰"时）

```
① 先客观测量 —— 别信肉眼，也别信体积
        ↓
② 再查源图分辨率 —— 找根因
        ↓
③ 修根因（重生成高分辨率源）
        ↓
④ 最后才考虑输出档位
```

### ① 客观测量：Laplacian 方差 + 边缘梯度

**必须统一缩放到同一宽度再比**，否则分辨率差异会污染结论。

```python
import cv2, numpy as np

def sharpness(path, norm_width=1181):
    img = cv2.imread(path, cv2.IMREAD_GRAYSCALE)
    h, w = img.shape
    if w != norm_width:                      # 统一宽度再测
        img = cv2.resize(img, (norm_width, int(h * norm_width / w)), interpolation=cv2.INTER_LANCZOS4)
    lap = cv2.Laplacian(img, cv2.CV_64F).var()          # 越高越锐
    grad = cv2.Sobel(img, cv2.CV_64F, 1, 0, ksize=3)
    return round(lap, 1), round(float(np.abs(grad).mean()), 2)

print(sharpness("成片.jpg"))
```

**判读标准**：

| 情况 | 结论 |
|---|---|
| 成片 Laplacian 明显低于源图 | 缩放过度或源图本身糊 |
| 成片 Laplacian 达到源图的 1.3 倍以上 | **过度锐化**，会出现光晕，要降下去 |
| 理想区间 | 成片 ≈ 源图的 1.0–1.1 倍 |

### ② 查源图分辨率 —— 最常见的真根因

**生图 prompt 没写分辨率要求 → 模型只给 800×1120 → 放大到 1181×1653 必然虚。**

这是出现频率最高的一类"不清晰"，修法是**重新生成高分辨率源图**，而不是把输出尺寸调大（放大糊图只会得到更大的糊图）。

| 源图宽度 | 放大到 1181 后 | 结论 |
|---|---|---|
| 2448 | 缩小 0.48× | 细节扎实 |
| 1728 | 缩小 0.68× | 够用 |
| 800 | **放大 1.48×** | ⚠️ 必糊，重做 |

### ③ 输出档位

档位定义与像素见 `specs.md` 第四节。核心三条：

- 主交付用**高清档**，不要把 300dpi 档当成品
- **超清版只在源图裁剪后仍 ≥ 高清档宽度时才出**，否则是插值假细节
- 三档输出到**不同目录**，避免同名覆盖

## 三、生成后质量检查清单

- [ ] 背景颜色是否均匀，没有杂色、渐变、阴影
- [ ] 人物是否正面，双肩是否水平
- [ ] 双耳和眉毛是否都露出，头发是否遮挡面部
- [ ] 表情是否自然，是否闭口不露齿
- [ ] 衣服是否符合规格要求（深色、有领、非制式）
- [ ] 面部特征是否与参考照片一致（**相似性第一优先级**）
- [ ] 宽高比是否正确
- [ ] 头部高度占比是否在 60–70%
- [ ] 鼻翼 / 鼻孔是否左右对称
- [ ] 白底是否**纯净白**（不是灰白或偏黄）

## 四、皮肤质感三档（prompt 可调）

| 用户想要 | prompt 里皮肤部分写 | 过审风险 |
|---|---|---|
| 真实原生（默认） | 「不要磨皮」 | 低，推荐政务用途 |
| 折中（细腻但有纹理） | 「皮肤自然细腻、肤色均匀有光泽、保留真实纹理但去除瑕疵」 | 低 |
| 精修感 | 「皮肤光滑细腻、肤色白皙透亮」 | **高**，部分系统有美颜检测 |

> ⚠️ **对比不同版本的皮肤质感时，必须同底图、同服装、同发型。** 衣服反光和发型光影会污染肤色观感，不同变量的对比结论不可靠。
>
> ⚠️ **政务用途优先真实路线**。过度美颜（磨皮 + 瘦脸 + 提亮）不仅有被系统判为"非原始影像"的风险，实际办理时人脸比对也可能不通过。

## 五、锐化参数（写进脚本，不要手动改）

按缩放比自适应：

| 源图 / 目标 | USM 强度 | 说明 |
|---|---|---|
| ≥ 1.2（大幅缩小） | 32% | 缩图本身会提升锐度，少加 |
| 1.0–1.2（小幅缩小） | 45% | 中间档 |
| < 1.0（放大） | 40% | 放大不产生细节，锐化只为观感 |

验收时回到第二节 ① 测一遍：**成片锐度控制在源图的 1.1 倍以内**。
