# 服装库与着装规则

## 一、着装冲突规则（重要，先检查再生成）

| 冲突 | 后果 | 规则 |
|---|---|---|
| **白色 / 浅色上衣 + 白底** | 衣服与背景融为一体，人像像浮在半空 | **强制换深色**（黑、深蓝、深灰、深棕、墨绿、酒红皆可） |
| 蓝色系上衣 + 蓝底 | 衣服融入背景，肩线消失 | 换非蓝色系，或加深衣服明度 |
| 红色系上衣 + 红底 | 同上 | 换非红色系 |
| 制式服装（军装/警服/校服/工装） | 身份证、护照等规格明确不允许 | 换普通深色正装 |
| 高领 / 遮脖子的领型 | 头部与身体比例失调，过审风险 | 选有领衬衫或西装，露出颈部线条 |
| 白色衬衫**单独出现**（无外套） | 白底场景下仍偏轻，且显单薄 | 白衬衫 + 深色西装外套是安全组合；只穿白衬衫时务必配蓝/红底 |

> **万能安全牌**：深色西装 + 白衬衫。几乎适配所有规格与底色。

## 二、男士服装风格库

| 风格 | 服装描述 | 适用场景 |
|---|---|---|
| 经典正式 | 黑色西装 + 白衬衫 | 身份证、正式证件、通用首选 |
| 沉稳商务 | 深藏青西装 + 白衬衫 | 驾驶证、工作证 |
| 低调干练 | 深灰西装 + 白衬衫 | 简历、面试 |
| 简约精神 | 纯黑衬衫（无外套） | 简约风格、年轻用户 |
| 庄重正式 | 藏青立领制服 | 正式场合、特殊行业 |
| 柔和稳重 | 深棕西装 + 浅色衬衫 | 温和风格 |
| 亲和自然 | 墨绿衬衫 / 酒红衬衫（无外套） | 需要一点色彩、避免全黑的场合 |

> 单穿衬衫的色系可选：黑、深蓝、深灰、墨绿、深棕、酒红。**深蓝最百搭，黑色最正式，酒红最有个性**（但酒红在部分系统里饱和度偏高，注意别过艳）。

## 三、女士服装风格库

| 风格 | 服装描述 | 适用场景 |
|---|---|---|
| 经典正式 | 黑色西装 + 白衬衫 | 身份证、正式证件、通用首选 |
| 温柔知性 | 米白 / 浅粉衬衫 | 简历、文职 |
| 干练职业 | 藏青西装 + 浅蓝衬衫 | 职场、工作证 |
| 简约大方 | 黑色上衣（领口简洁） | 通用 |
| 沉稳深色 | 深灰 / 深蓝西装 + 浅色衬衫 | 需要更沉稳的场合 |

> 女士同样适用第一节的冲突规则 —— 米白、浅粉这类浅色上衣**不能配白底**，务必配蓝底或红底，或加一件深色外套。

## 四、prompt 里的服装写法

在生图 prompt 里描述服装时，写**材质 + 颜色 + 款式 + 领型**，比只写颜色稳定得多：

```
穿深酒红色纯色修身长袖衬衫，翻领，无图案无logo，面料挺括
```

反面写法（容易跑偏）：`穿衬衫` / `商务装` / `正式衣服`。

## 五、命名约定

文件名格式：`<规格><底色>_<特征>_<风格>.jpg`

```
一寸白底_黑色衬衫_经典正式.jpg
一寸白底_微分碎盖_自然清爽.jpg
```

- **特征** = 服装（黑色衬衫）或发型（微分碎盖）
- **风格** = 场景气质，**不是颜色也不是发型**。可选：经典正式、沉稳商务、低调干练、简约精神、庄重正式、柔和稳重、自然清爽
