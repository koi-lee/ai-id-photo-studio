## 计划中

### 六寸排版打印

把单张证件照按 6 寸相纸（152×102mm @300dpi ≈ 1795×1205）排版成多张，便于冲印和裁切。

- 优点：成本低（一张 6 寸相纸可排 8 张一寸照），避免单张冲印的浪费
- 参考：`HivisionIDPhotos` 的排版功能
- 关键点：留裁切标记、间距一致、底色连贯

### 合规自检脚本

把人工肉眼检查固化成脚本，输出可复核的报告：

- [ ] 底色纯净度（采样四角与边缘，检测杂色/渐变/阴影）
- [ ] 头部高度占比（人脸关键点定位，校验 60–70%）
- [ ] 双肩水平度
- [ ] 文件大小上限（部分系统有硬性限制）
- [ ] 宽高比与目标规格一致性

> 该脚本能覆盖 `quality.md` 第三节质量清单里可量化的大部分条目，减少对人工目视的依赖。

### 更多规格与场景

- [ ] 护照 / 签证专用规格校验（部分国家对背景灰度、头部占比有额外要求）
- [ ] 学位照 / 学位证规格
- [ ] 各国签证规格库（美签 51×51mm 方形等）

### 通道扩展

- [ ] 更多第三方生图 API 的适配（当前以美图设计室为实例）
- [ ] 本地推理通道（如 `HivisionIDPhotos` 的抠图换底能力）作为零额度兜底

### 工程化

- [ ] `--sharpen-target`：自动匹配源图锐度（目标 = 源图 Laplacian × 1.05）
- [ ] `scripts/quality_report.py`：一条命令输出修图前后的客观对比表
- [ ] 把 `selfcheck.py` 的尺寸校验扩展为 pytest 用例（补裁剪逻辑与边界条件的覆盖）

## 不做

- **不做人脸生成模型**。本项目定位是编排与后处理，模型能力依赖外部通道；重造轮子没有意义。
- **不做云端服务**。证件照含生物识别特征，本地处理是隐私底线。
